# page-source-check

홈페이지 페이지 소스(누구나 볼 수 있는 HTML·CSS·JS)에 남은 작업 메모, 개인정보, 비밀키를 찾아 주고, 원하면 화면은 그대로 두고 지워 주는 클로드 코드 스킬이에요.

AI로 만든 홈페이지 50곳을 열어 보니 절반인 25곳에 작업 메모가 남아 있었어요. 그걸 점검할 때 쓴 스킬이에요.

## 설치 (1분)

1. 이 저장소의 `skills/page-source-check/SKILL.md` 파일을 내려받아요.
2. 내 컴퓨터의 `~/.claude/skills/page-source-check/` 폴더에 넣어요. (폴더가 없으면 만들어요.)
   - 맥: Finder에서 ⇧⌘G → `~/.claude/skills` 입력
3. 클로드 코드를 다시 열어요.

또는 클로드 코드에 이렇게 말해도 돼요.
> 이 저장소의 skills/page-source-check 폴더를 ~/.claude/skills/ 에 설치해 줘: [저장소 주소]

## 쓰는 법

```
/page-source-check https://우리홈페이지.com
```

- 점검만 하고, "지워 줘"라고 해야 고쳐요.
- 고칠 때는 원본을 백업하고, 고친 뒤 다시 점검해서 0개인지, 화면이 그대로인지 확인해요.
- 배포는 하지 않아요. 고친 파일 위치만 알려 줘요.
- 비밀키가 나오면 소스에서 지우는 것만으로는 부족해요. 키를 발급한 곳에서 새 키로 바꿔야 해요.

## 손으로 확인하는 법 (3초)

홈페이지에서 오른쪽 클릭 → '페이지 소스 보기' (맥 ⌥⌘U, 윈도우 Ctrl+U) → Ctrl+F(맥 ⌘F)로 `<!--` 와 `/*` 검색.
초록색 글씨가 화면엔 안 보이는 메모예요.

## 주의

남의 사이트는 누구나 보는 페이지 소스만 보세요. 설정 파일(.env 등)이 열리는지 찔러 보는 건 허락 없는 보안 점검이 될 수 있어요. 이 스킬의 설정 파일 확인은 내 사이트에만 쓰세요.
